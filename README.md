# SQL Server Practice

A collection of SQL queries and practical exercises covering database fundamentals, joins, subqueries, CTEs, window functions, stored procedures, and problem-solving.

## Topics Covered

- SQL Basics
- SELECT, WHERE & ORDER BY
- GROUP BY & HAVING
- Joins
- Subqueries
- CTEs
- Window Functions
- RANK, DENSE_RANK & ROW_NUMBER
- Temporary Tables
- Views
- Stored Procedures
- Constraints
- Aggregate Functions
- Problem Solving

## Technologies

- SQL
- SQL Server
- SQL Server Management Studio (SSMS)
